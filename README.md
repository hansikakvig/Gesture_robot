# 🤖 Gesture Robot Lab

An interactive **AI-powered Gesture Controlled Robot** that understands hand gestures through the camera and makes the 3D robot perform different actions in real time.

The robot can understand gestures like **YES, NO, LOVE, WAVE, DANCE** and more — making the project a fun combination of **Computer Vision, AI and 3D Web Technology**.

---

## ✨ Features

- 🖐️ Real-time hand gesture detection
- 🤖 Interactive 3D robot
- 📷 Camera-based gesture recognition
- 🎮 Robot responds instantly to hand movements
- 💃 Multiple robot animations
- ❤️ Special gesture-based actions
- 🟢 Live gesture status
- 🌐 Runs directly in the browser

---

## 🧠 How It Works

```text
        📷 Camera
            ↓
     Hand Detection
            ↓
    Gesture Recognition
            ↓
     Gesture Mapping
            ↓
       🤖 3D Robot
            ↓
      Robot Animation
```

The camera captures the user's hand movements.  
The hand tracking system identifies the gesture and maps it to a specific robot action.

For example:

```text
👍 → YES
👎 → NO
🤟 → LOVE
✌️ → DANCE
🖐️ → WAVE
```

## 🎮 Robot Actions

### 👍 YES
Show a **Thumbs Up** gesture and the robot responds with the **YES** action.

### 👎 NO
Show a **Thumbs Down** gesture and the robot performs the **NO** response.

### 👋 WAVE
Show an **Open Palm** and the robot waves its hand.

### 💃 DANCE
Show the **Victory gesture ✌️** and the robot performs a dance animation.

### ❤️ LOVE
Show the **I Love You gesture 🤟** and the robot displays the LOVE action.

### 💪 POWER
Make a **Closed Fist ✊** and the robot performs the POWER action.

### 👉 POINT
Show a **Pointing Up ☝️** gesture and the robot points.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Open the Project

```bash
cd gesture-robot
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

Allow **camera permission** when asked.

## 🎯 Project Objective

The main objective of this project is to demonstrate how **hand gesture recognition** can be combined with **3D graphics and animation** to create an interactive human-computer interface.

Instead of using traditional buttons or keyboard controls, the user can control the robot using simple **hand gestures**.
